## Simplify Expressions Using the Commutative and Associative Properties


When we have to simplify algebraic expressions, we can often make the work easier by applying the Commutative or Associative Property first instead of automatically following the order of operations. Notice that in  part ⓑ was easier to simplify than part ⓐ because the opposites were next to each other and their sum is <span class="math-inline">0.</span> Likewise, part ⓑ in  was easier, with the reciprocals grouped together, because their product is <span class="math-inline">1.</span> In the next few examples, we’ll use our number sense to look for ways to apply these properties to make our work easier.


<div class="example">
**Example**


Simplify: <span class="math-inline">−84n+(−73n)+84n.</span>


<div class="solution">
<span class="def-label">Solution</span>


Notice the first and third terms are opposites, so we can use the commutative property of addition to reorder the terms.


   <span class="math-inline">−84n+(−73n)+84n</span>


   Re-order the terms.
   <span class="math-inline">−84n+84n+(−73n)</span>


   Add left to right.
   <span class="math-inline">0+(−73n)</span>


   Add.
   <span class="math-inline">−73n</span>

**Try It**

−48*a*


<div class="tryit">
**Try It**

Now we will see how recognizing reciprocals is helpful. Before multiplying left to right, look for reciprocals—their product is <span class="math-inline">1.</span>


<div class="example">
**Example**


Simplify: <span class="math-inline"><sup>7</sup>∕<sub>15</sub>· <sup>8</sup>∕<sub>23</sub>· <sup>15</sup>∕<sub>7</sub>.</span>


<div class="solution">
<span class="def-label">Solution</span>


Notice the first and third terms are reciprocals, so we can use the Commutative Property of Multiplication to reorder the factors.


   <span class="math-inline"><sup>7</sup>∕<sub>15</sub>· <sup>8</sup>∕<sub>23</sub>· <sup>15</sup>∕<sub>7</sub></span>


   Re-order the terms.
   <span class="math-inline"><sup>7</sup>∕<sub>15</sub>· <sup>15</sup>∕<sub>7</sub>· <sup>8</sup>∕<sub>23</sub></span>


   Multiply left to right.
   <span class="math-inline">1· <sup>8</sup>∕<sub>23</sub></span>


   Multiply.
   <span class="math-inline"><sup>8</sup>∕<sub>23</sub></span>

In expressions where we need to add or subtract three or more fractions, combine those with a common denominator first.


<div class="example">
**Example**

<div class="solution">
<span class="def-label">Solution</span>

   <span class="math-inline">(<sup>5</sup>∕<sub>13</sub>+<sup>3</sup>∕<sub>4</sub>)+<sup>1</sup>∕<sub>4</sub></span>


   Group the terms with a common denominator.
   <span class="math-inline"><sup>5</sup>∕<sub>13</sub>+(<sup>3</sup>∕<sub>4</sub>+<sup>1</sup>∕<sub>4</sub>)</span>

   <span class="math-inline"><sup>5</sup>∕<sub>13</sub>+(<sup>4</sup>∕<sub>4</sub>)</span>

   <span class="math-inline"><sup>5</sup>∕<sub>13</sub>+1</span>


   Add.
   <span class="math-inline">1<sup>5</sup>∕<sub>13</sub></span>

No matter what you are doing, it is always a good idea to think ahead. When simplifying an expression, think about what your steps will be. The next example will show you how using the Associative Property of Multiplication can make your work easier if you plan ahead.


<div class="example">
**Example**


Simplify the expression: <span class="math-inline">[1.67(8)](0.25).</span>


<div class="solution">
<span class="def-label">Solution</span>


Notice that multiplying <span class="math-inline">(8)(0.25)</span> is easier than multiplying <span class="math-inline">1.67(8)</span> because it gives a whole number. (Think about having <span class="math-inline">8</span> quarters—that makes <span class="math-inline">$2.)</span>


   <span class="math-inline">[1.67(8)](0.25)</span>


   Regroup.
   <span class="math-inline">1.67[(8)(0.25)]</span>


   Multiply in the brackets first.
   <span class="math-inline">1.67[2]</span>


   Multiply.
   <span class="math-inline">3.34</span>

## Key Concepts


- *Commutative Properties*
  - *Commutative Property of Addition:*
  - If <span class="math-inline">a,b</span> are real numbers, then <span class="math-inline">a+b=b+a</span>
  - *Commutative Property of Multiplication:*
  - If <span class="math-inline">a,b</span> are real numbers, then <span class="math-inline">a· b=b· a</span>

- *Associative Properties*
  - *Associative Property of Addition:*
  -


If <span class="math-inline">a,b,c</span> are real numbers then <span class="math-inline">(a+b)+c=a+(b+c)</span>


  - *Associative Property of Multiplication:*
  -


If <span class="math-inline">a,b,c</span> are real numbers then <span class="math-inline">(a· b)· c=a· (b· c)</span>

## Simplify Expressions Using the Distributive Property


Suppose three friends are going to the movies. They each need <span class="math-inline">$9.25;</span> that is, <span class="math-inline">9</span> dollars and <span class="math-inline">1</span> quarter. How much money do they need all together? You can think about the dollars separately from the quarters.

They need <span class="math-inline">3</span> times <span class="math-inline">$9,</span> so <span class="math-inline">$27,</span> and <span class="math-inline">3</span> times <span class="math-inline">1</span> quarter, so <span class="math-inline">75</span> cents. In total, they need <span class="math-inline">$27.75.</span>

If you think about doing the math in this way, you are using the Distributive Property.


<div class="definition-label">**Distributive Property**</div>


If <span class="math-inline">a,b,c</span> are real numbers, then


<div class="math-display">
a(b+c)=ab+ac
</div>


Back to our friends at the movies, we could show the math steps we take to find the total amount of money they need like this:


<div class="math-display">
& 3 &  \\
3 & + & 0.25 \\
3 & + & 3 \\
27 & + & 0.75 \\
 & 27.75 &
</div>


In algebra, we use the Distributive Property to remove parentheses as we simplify expressions. For example, if we are asked to simplify the expression <span class="math-inline">3(x+4),</span> the order of operations says to work in the parentheses first. But we cannot add <span class="math-inline">x</span> and <span class="math-inline">4,</span> since they are not like terms. So we use the Distributive Property, as shown in .


<div class="example">
**Example**


Simplify: <span class="math-inline">3(x+4).</span>


<div class="solution">
<span class="def-label">Solution</span>


   <span class="math-inline">3(x+4)</span>


   Distribute.
   <span class="math-inline">3· x+3· 4</span>


   Multiply.
   <span class="math-inline">3x+12</span>
