- *Coordinates of Zero*
  - Points with a *y-*coordinate equal to 0 are on the *x-*axis, and have coordinates ( *a*, 0).
  - Points with a *x-*coordinate equal to 0 are on the *y-*axis, and have coordinates ( 0, *b*).
  - The point (0, 0) is called the origin. It is the point where the *x-*axis and *y-*axis intersect.

## Recognize the Relation Between the Solutions of an Equation and its Graph


In Use the Rectangular Coordinate System, we found a few solutions to the equation <span class="math-inline">3x+2y=6</span>.
They are listed in the table below.
So, the ordered pairs <span class="math-inline">(0,3)</span>, <span class="math-inline">(2,0)</span>, <span class="math-inline">(1,<sup>3</sup>⁄<sub>2</sub>)</span>, <span class="math-inline">(4,-3)</span>, are some solutions to the equation<span class="math-inline">3x+2y=6</span>.
We can plot these solutions in the rectangular coordinate system as shown on the graph at right.


Notice how the points line up perfectly?  We connect the points with a straight line to get the graph of the equation <span class="math-inline">3x+2y=6</span>.  Notice the arrows on the ends of each side of the line.  These arrows indicate the line continues.

Every point on the line is a solution of the equation. Also, every solution of this equation is a point on this line. Points not on the line are *not* solutions!

Notice that the point whose coordinates are <span class="math-inline">(-2,6)</span>  is on the line shown in . If you substitute <span class="math-inline">x=-2</span>  and <span class="math-inline">y=6</span>  into the equation, you find that it is a solution to the equation.

So <span class="math-inline">(4,1)</span>  is not a solution to the equation <span class="math-inline">3x+2y=6</span> . Therefore the point <span class="math-inline">(4,1)</span> is not on the line.


This is an example of the saying,” A picture is worth a thousand words.”  The line shows you all the solutions to the equation. Every point on the line is a solution of the equation. And, every solution of this equation is on this line. This line is called the *graph* of the equation <span class="math-inline">3x+2y=6</span>.


**Graph of a Linear Equation**

- Every point on the line is a solution of the equation.

- Every solution of this equation is a point on this line.

## Graph a Linear Equation by Plotting Points

There are several methods that can be used to graph a linear equation. The method we used at the start of this section to graph is called plotting points, or the **Point-Plotting Method**.

Let’s graph the equation <span class="math-inline">y=2x+1</span> by plotting points.

We start by finding three points that are solutions to the equation. We can choose any value for <span class="math-inline">x</span> or <span class="math-inline">y,</span> and then solve for the other variable.


Since <span class="math-inline">y</span> is isolated on the left side of the equation, it is easier to choose values for <span class="math-inline">x.</span> We will use <span class="math-inline">0,1,</span> and <span class="math-inline">-2</span> for <span class="math-inline">x</span> for this example.
We substitute each value of <span class="math-inline">x</span> into the equation and solve for <span class="math-inline">y.</span>


We can organize the solutions in a table. See .


Now we plot the points on a rectangular coordinate system. Check that the points line up. If they did not line up, it would mean we made a mistake and should double-check all our work. See .

Draw the line through the three points. Extend the line to fill the grid and put arrows on both ends of the line. The line is the graph of <span class="math-inline">y=2x+1.</span>


**Graph a linear equation by plotting points.**

- Find three points whose coordinates are solutions to the equation. Organize them in a table.

- Plot the points on a rectangular coordinate system. Check that the points line up. If they do not, carefully check your work.

- Draw the line through the points. Extend the line to fill the grid and put arrows on both ends of the line.


It is true that it only takes two points to determine a line, but it is a good habit to use three points.
If you plot only two points and one of them is incorrect, you can still draw a line but it will not represent the solutions to the equation.
It will be the wrong line.
If you use three points, and one is incorrect, the points will not line up.
This tells you something is wrong and you need to check your work.

The equations for vertical and horizontal lines look very similar to equations like <span class="math-inline">y=4x.</span> What is the difference between the equations <span class="math-inline">y=4x</span> and <span class="math-inline">y=4?</span>

The equation <span class="math-inline">y=4x</span> has both <span class="math-inline">x</span> and <span class="math-inline">y.</span> The value of <span class="math-inline">y</span> depends on the value of <span class="math-inline">x.</span> The <span class="math-inline">y-coordinate</span> changes according to the value of <span class="math-inline">x.</span>

The equation <span class="math-inline">y=4</span> has only one variable. The value of <span class="math-inline">y</span> is constant. The <span class="math-inline">y-coordinate</span> is always <span class="math-inline">4.</span> It does not depend on the value of <span class="math-inline">x.</span>

The graph shows both equations.

Notice that the equation <span class="math-inline">y=4x</span> gives a slanted line whereas <span class="math-inline">y=4</span> gives a horizontal line.
