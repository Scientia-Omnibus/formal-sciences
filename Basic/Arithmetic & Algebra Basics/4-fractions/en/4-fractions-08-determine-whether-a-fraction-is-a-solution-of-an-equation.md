## Determine Whether a Fraction is a Solution of an Equation


As we saw in Solve Equations with the Subtraction and Addition Properties of Equality and Solve Equations Using Integers; The Division Property of Equality, a solution of an equation is a value that makes a true statement when substituted for the variable in the equation. In those sections, we found whole number and integer solutions to equations. Now that we have worked with fractions, we are ready to find fraction solutions to equations.

The steps we take to determine whether a number is a solution to an equation are the same whether the solution is a whole number, an integer, or a fraction.


<div class="definition-label">**Determine whether a number is a solution to an equation.**</div>


- Substitute the number for the variable in the equation.

- Simplify the expressions on both sides of the equation.

- Determine whether the resulting equation is true. If it is true, the number is a solution. If it is not true, the number is not a solution.


<div class="example">
**Example**


Determine whether each of the following is a solution of <span class="math-inline">x-<sup>3</sup>∕<sub>10</sub>=<sup>1</sup>∕<sub>2</sub>.</span>

  - ⓐ <span class="math-inline">x=1</span>
  - ⓑ <span class="math-inline">x=<sup>4</sup>∕<sub>5</sub></span>
  - ⓒ <span class="math-inline">x=-<sup>4</sup>∕<sub>5</sub></span>


<div class="solution">
<span class="def-label">Solution</span>


   ⓐ


   Change to fractions with a LCD of 10.


   Subtract.


Since <span class="math-inline">x=1</span> does not result in a true equation, <span class="math-inline">1</span> is not a solution to the equation.


   ⓑ


   Subtract.


Since <span class="math-inline">x=<sup>4</sup>∕<sub>5</sub></span> results in a true equation, <span class="math-inline"><sup>4</sup>∕<sub>5</sub></span> is a solution to the equation <span class="math-inline">x-<sup>3</sup>∕<sub>10</sub>=<sup>1</sup>∕<sub>2</sub>.</span>


   ⓒ


   Subtract.


Since <span class="math-inline">x=-<sup>4</sup>∕<sub>5</sub></span> does not result in a true equation, <span class="math-inline">-<sup>4</sup>∕<sub>5</sub></span> is not a solution to the equation.

## Solve Equations with Fractions Using the Multiplication Property of Equality


Consider the equation <span class="math-inline"><sup>x</sup>∕<sub>4</sub>=3.</span> We want to know what number divided by <span class="math-inline">4</span> gives <span class="math-inline">3.</span> So to “undo” the division, we will need to multiply by <span class="math-inline">4.</span> The *Multiplication Property of Equality* will allow us to do this. This property says that if we start with two equal quantities and multiply both by the same number, the results are equal.


<div class="definition-label">**The Multiplication Property of Equality**</div>


For any numbers <span class="math-inline">a,b,</span> and <span class="math-inline">c,</span>


<div class="math-display">
if a=b,then ac=bc.
</div>


If you multiply both sides of an equation by the same quantity, you still have equality.

<span class="def-label">Solution</span>


    Use the Multiplication Property of Equality to multiply both sides by <span class="math-inline">7</span>. This will isolate the variable.


    Multiply.

There are three different ways to isolate the variable in this type of equation. We will show all three ways in .


<div class="example">
**Example**


Solve: <span class="math-inline">-y=15.</span>


<div class="solution">
<span class="def-label">Solution</span>


One way to solve the equation is to rewrite <span class="math-inline">-y</span> as <span class="math-inline">−1y,</span> and then use the Division Property of Equality to isolate <span class="math-inline">y.</span>


   Rewrite <span class="math-inline">-y</span> as <span class="math-inline">−1y</span>.


   Divide both sides by −1.


   Simplify each side.


Another way to solve this equation is to multiply both sides of the equation by <span class="math-inline">−1.</span>


   Multiply both sides by −1.


   Simplify each side.


The third way to solve the equation is to read <span class="math-inline">-y</span> as “the opposite of <span class="math-inline">y</span>.” What number has <span class="math-inline">15</span> as its opposite? The opposite of <span class="math-inline">15</span> is <span class="math-inline">−15.</span> So <span class="math-inline">y=−15.</span>
For all three methods, we isolated <span class="math-inline">y</span> is isolated and solved the equation.
