## Solve Equations with Fraction Coefficients


Let’s use the General Strategy for Solving Linear Equations introduced earlier to solve the equation <span class="math-inline"><sup>1</sup>∕<sub>8</sub> x+<sup>1</sup>∕<sub>2</sub>=<sup>1</sup>∕<sub>4</sub>.</span>


This method worked fine, but many students don’t feel very confident when they see all those fractions. So we are going to show an alternate method to solve equations with fractions. This alternate method eliminates the fractions.

We will apply the **Multiplication Property of Equality** and multiply both sides of an equation by the least common denominator of *all* the fractions in the equation. The result of this operation will be a new equation, equivalent to the first, but with no fractions. This process is called *clearing the equation of fractions*. Let’s solve the same equation again, but this time use the method that clears the fractions.


<div class="example">
**Example**


Solve: <span class="math-inline"><sup>1</sup>∕<sub>8</sub> x+<sup>1</sup>∕<sub>2</sub>=<sup>1</sup>∕<sub>4</sub>.</span>


<div class="solution">
<span class="def-label">Solution</span>


 Find the least common denominator of *all* the fractions in the equation.


Multiply both sides of the equation by that LCD, 8. This clears the fractions.


Use the Distributive Property.


Simplify — and notice, no more fractions!


Solve using the General Strategy for Solving Linear Equations.


Simplify.

<div class="definition-label">**Solve equations with fraction coefficients by clearing the fractions.**</div>


- Find the least common denominator of *all* the fractions in the equation.

- Multiply both sides of the equation by that LCD. This clears the fractions.

- Solve using the General Strategy for Solving Linear Equations.

## Solve Equations with Decimal Coefficients


Some equations have decimals in them. This kind of equation will occur when we solve problems dealing with money and percent. But decimals are really another way to represent fractions. For example, <span class="math-inline">0.3=<sup>3</sup>∕<sub>10</sub></span> and <span class="math-inline">0.17=<sup>17</sup>∕<sub>100</sub>.</span> So, when we have an equation with decimals, we can use the same process we used to clear fractions—multiply both sides of the equation by the **least common denominator**.


<div class="example">
**Example**


Solve: <span class="math-inline">0.8x-5=7.</span>


<div class="solution">
<span class="def-label">Solution</span>


The only decimal in the equation is <span class="math-inline">0.8.</span> Since <span class="math-inline">0.8=<sup>8</sup>∕<sub>10</sub>,</span> the LCD is <span class="math-inline">10.</span> We can multiply both sides by <span class="math-inline">10</span> to clear the decimal.


Multiply both sides by the LCD.


Distribute.


Multiply, and notice, no more decimals!


Add 50 to get all constants to the right.


Simplify.


Divide both sides by 8.


Simplify.

<span class="def-label">Check</span>

<div class="solution">

<span class="math-inline">0.06=<sup>6</sup>∕<sub>100</sub>, 0.02=<sup>2</sup>∕<sub>100</sub>, 0.25=<sup>25</sup>∕<sub>100</sub>, 1.5=1<sup>5</sup>∕<sub>10</sub></span>Notice, the LCD is <span class="math-inline">100.</span>
By multiplying by the LCD we will clear the decimals.


Multiply both sides by 100.


Distribute.
