## Use the Basic Definition of Probability


The **probability** of an event tells us how likely that event is to occur. We usually write probabilities as fractions or decimals.

For example, picture a fruit bowl that contains five pieces of fruit - three bananas and two apples.

If you want to choose one piece of fruit to eat for a snack and don’t care what it is, there is a <span class="math-inline"><sup>3</sup>∕<sub>5</sub></span> probability you will choose a banana, because there are three bananas out of the total of five pieces of fruit. The probability of an event is the number of favorable outcomes divided by the total number of outcomes.


<div class="definition-label">**Probability**</div>


The **probability** of an event is the number of favorable outcomes divided by the total number of outcomes possible.


<div class="math-display">
Probability=<sup>number of favorable outcomes</sup>∕<sub>total number of outcomes</sub>
</div>


Converting the fraction <span class="math-inline"><sup>3</sup>∕<sub>5</sub></span> to a decimal, we would say there is a <span class="math-inline">0.6</span> probability of choosing a banana.

</div>


This basic definition of **probability** assumes that all the outcomes are equally likely to occur. If you study probabilities in a later math class, you’ll learn about several other ways to calculate probabilities.

## Key Concepts


- *Calculate the mean of a set of numbers.*

  - Write the formula for the mean <span class="math-inline">mean=<sup>sum of values in data set</sup>∕<sub>n</sub></span>
  - Find the sum of all the values in the set. Write the sum in the numerator.
  - Count the number, *n*, of values in the set. Write this number in the denominator.
  - Simplify the fraction.
  - Check to see that the mean is reasonable. It should be greater than the least number and less than the greatest number in the set.

- *Find the median of a set of numbers.*

  - List the numbers from least to greatest.
  - Count how many numbers are in the set. Call this <span class="math-inline">n</span>.
  - Is <span class="math-inline">n</span> odd or even?

If <span class="math-inline">n</span> is an odd number, the median is the middle value.

If <span class="math-inline">n</span> is an even number, the median is the mean of the two middle values

- *Identify the mode of a set of numbers.*

  - List the data values in numerical order.
  - Count the number of times each value appears.
  - The mode is the value with the highest frequency.

## Write a Ratio as a Fraction


When you apply for a mortgage, the loan officer will compare your total debt to your total income to decide if you qualify for the loan. This comparison is called the debt-to-income ratio. A **ratio** compares two quantities that are measured with the same unit. If we compare <span class="math-inline">a</span> and <span class="math-inline">b</span>, the ratio is written as <span class="math-inline">a to b, <sup>a</sup>∕<sub>b</sub>, or a:b.</span>


<div class="definition-label">**Ratios**</div>


A **ratio** compares two numbers or two quantities that are measured with the same unit. The ratio of <span class="math-inline">a</span> to <span class="math-inline">b</span> is written <span class="math-inline">a to b, <sup>a</sup>∕<sub>b</sub>, or a:b.</span>

In this section, we will use the fraction notation. When a ratio is written in fraction form, the fraction should be simplified. If it is an improper fraction, we do not change it to a mixed number. Because a ratio compares two quantities, we would leave a ratio as <span class="math-inline"><sup>4</sup>∕<sub>1</sub></span> instead of simplifying it to <span class="math-inline">4</span> so that we can see the two parts of the ratio.


<div class="example">
**Example**


Write each ratio as a fraction: ⓐ <span class="math-inline">15 to 27</span>ⓑ <span class="math-inline">45 to 18.</span>

ⓐ


<span class="math-inline">15 to 27</span>


Write as a fraction with the first number in the numerator and the second in the denominator.
<span class="math-inline"><sup>15</sup>∕<sub>27</sub></span>


Simplify the fraction.
<span class="math-inline"><sup>5</sup>∕<sub>9</sub></span>


ⓑ


<span class="math-inline">45 to 18</span>


Write as a fraction with the first number in the numerator and the second in the denominator.
<span class="math-inline"><sup>45</sup>∕<sub>18</sub></span>


Simplify.
<span class="math-inline"><sup>5</sup>∕<sub>2</sub></span>


We leave the ratio in ⓑ as an improper fraction.

### Ratios Involving Decimals

We will often work with ratios of decimals, especially when we have ratios involving money. In these cases, we can eliminate the decimals by using the Equivalent Fractions Property to convert the ratio to a fraction with whole numbers in the numerator and denominator.

For example, consider the ratio <span class="math-inline">0.8 to 0.05.</span> We can write it as a fraction with decimals and then multiply the numerator and denominator by <span class="math-inline">100</span> to eliminate the decimals.

Do you see a shortcut to find the equivalent fraction? Notice that <span class="math-inline">0.8=<sup>8</sup>∕<sub>10</sub></span> and <span class="math-inline">0.05=<sup>5</sup>∕<sub>100</sub>.</span> The least common denominator of <span class="math-inline"><sup>8</sup>∕<sub>10</sub></span> and <span class="math-inline"><sup>5</sup>∕<sub>100</sub></span> is <span class="math-inline">100.</span> By multiplying the numerator and denominator of <span class="math-inline"><sup>0.8</sup>∕<sub>0.05</sub></span> by <span class="math-inline">100,</span> we ‘moved’ the decimal two places to the right to get the equivalent fraction with no decimals. Now that we understand the math behind the process, we can find the fraction with no decimals like this:


You do not have to write out every step when you multiply the numerator and denominator by powers of ten. As long as you move both decimal places the same number of places, the ratio will remain the same.

**Example**


Write each ratio as a fraction of whole numbers:


  -
ⓐ <span class="math-inline">4.8 to 11.2</span>

  -
ⓑ <span class="math-inline">2.7 to 0.54</span>


<div class="solution">
<span class="def-label">Solution</span>


ⓐ <span class="math-inline">4.8 to 11.2</span>


Write as a fraction.
<span class="math-inline"><sup>4.8</sup>∕<sub>11.2</sub></span>


Rewrite as an equivalent fraction without decimals, by moving both decimal points 1 place to the right.
<span class="math-inline"><sup>48</sup>∕<sub>112</sub></span>


Simplify.
<span class="math-inline"><sup>3</sup>∕<sub>7</sub></span>


So <span class="math-inline">4.8 to 11.2</span> is equivalent to <span class="math-inline"><sup>3</sup>∕<sub>7</sub>.</span>


ⓑ

The numerator has one decimal place and the denominator has <span class="math-inline">2.</span> To clear both decimals we need to move the decimal <span class="math-inline">2</span> places to the right.
<span class="math-inline">2.7 to 0.54</span>


Write as a fraction.
<span class="math-inline"><sup>2.7</sup>∕<sub>0.54</sub></span>


Move both decimals right two places.
<span class="math-inline"><sup>270</sup>∕<sub>54</sub></span>


Simplify.
<span class="math-inline"><sup>5</sup>∕<sub>1</sub></span>


So <span class="math-inline">2.7 to 0.54</span> is equivalent to <span class="math-inline"><sup>5</sup>∕<sub>1</sub>.</span>

### Applications of Ratios

One real-world application of ratios that affects many people involves measuring cholesterol in blood. The ratio of total cholesterol to HDL cholesterol is one way doctors assess a person's overall health. A ratio of less than <span class="math-inline">5</span> to <span class="math-inline">1</span> is considered good.


<div class="example">
**Example**


Hector's total cholesterol is <span class="math-inline">249</span> mg/dl and his HDL cholesterol is <span class="math-inline">39</span> mg/dl. ⓐ Find the ratio of his total cholesterol to his HDL cholesterol. ⓑ Assuming that a ratio less than <span class="math-inline">5</span> to <span class="math-inline">1</span> is considered good, what would you suggest to Hector?


<div class="solution">
<span class="def-label">Solution</span>


ⓐ First, write the words that express the ratio. We want to know the ratio of Hector's total cholesterol to his HDL cholesterol.


   Write as a fraction.
   <span class="math-inline"><sup>total cholesterol</sup>∕<sub>HDL cholesterol</sub></span>


 Substitute the values.
 <span class="math-inline"><sup>249</sup>∕<sub>39</sub></span>


   Simplify.
   <span class="math-inline"><sup>83</sup>∕<sub>13</sub></span>


ⓑ Is Hector's cholesterol ratio ok? If we divide <span class="math-inline">83</span> by <span class="math-inline">13</span> we obtain approximately <span class="math-inline">6.4,</span> so <span class="math-inline"><sup>83</sup>∕<sub>13</sub>≈ <sup>6.4</sup>∕<sub>1</sub>.</span> Hector's cholesterol ratio is high! Hector should either lower his total cholesterol or raise his HDL cholesterol.

#### Ratios of Two Measurements in Different Units

To find the ratio of two measurements, we must make sure the quantities have been measured with the same unit. If the measurements are not in the same units, we must first convert them to the same units.

We know that to simplify a fraction, we divide out common factors. Similarly in a ratio of measurements, we divide out the common unit.


<div class="example">
**Example**


The Americans with Disabilities Act (ADA) Guidelines for wheel chair ramps require a maximum vertical rise of <span class="math-inline">1</span> inch for every <span class="math-inline">1</span> foot of horizontal run. What is the ratio of the rise to the run?


<div class="solution">
<span class="def-label">Solution</span>


In a ratio, the measurements must be in the same units. We can change feet to inches, or inches to feet. It is usually easier to convert to the smaller unit, since this avoids introducing more fractions into the problem.
Write the words that express the ratio.


 Ratio of the rise to the run


 Write the ratio as a fraction.
 <span class="math-inline"><sup>rise</sup>∕<sub>run</sub></span>


 Substitute in the given values.
 <span class="math-inline"><sup>1 inch</sup>∕<sub>1 foot</sub></span>


 Convert 1 foot to inches.
 <span class="math-inline"><sup>1 inch</sup>∕<sub>12 inches</sub></span>


 Simplify, dividing out common factors and units.
 <span class="math-inline"><sup>1</sup>∕<sub>12</sub></span>


So the ratio of rise to run is <span class="math-inline">1</span> to <span class="math-inline">12.</span> This means that the ramp should rise <span class="math-inline">1</span> inch for every <span class="math-inline">12</span> inches of horizontal run to comply with the guidelines.

## Write a Rate as a Fraction


Frequently we want to compare two different types of measurements, such as miles to gallons. To make this comparison, we use a **rate**. Examples of rates are <span class="math-inline">120</span> miles in <span class="math-inline">2</span> hours, <span class="math-inline">160</span> words in <span class="math-inline">4</span> minutes, and <span class="math-inline">$5</span> dollars per <span class="math-inline">64</span> ounces.


<div class="definition-label">**Rate**</div>


A **rate** compares two quantities of different units. A rate is usually written as a fraction.

When writing a fraction as a rate, we put the first given amount with its units in the numerator and the second amount with its units in the denominator. When rates are simplified, the units remain in the numerator and denominator.


<div class="example">
**Example**


Bob drove his car <span class="math-inline">525</span> miles in <span class="math-inline">9</span> hours. Write this rate as a fraction.


<div class="solution">
<span class="def-label">Solution</span>


 <span class="math-inline">525 miles in 9 hours</span>


 Write as a fraction, with 525 miles in the numerator and 9 hours in the denominator.
 <span class="math-inline"><sup>525 miles</sup>∕<sub>9 hours</sub></span>


 <span class="math-inline"><sup>175 miles</sup>∕<sub>3 hours</sub></span>


So <span class="math-inline">525</span> miles in <span class="math-inline">9</span> hours is equivalent to <span class="math-inline"><sup>175 miles</sup>∕<sub>3 hours</sub>.</span>

## Find Unit Rates


In the last example, we calculated that Bob was driving at a rate of <span class="math-inline"><sup>175 miles</sup>∕<sub>3 hours</sub>.</span> This tells us that every three hours, Bob will travel <span class="math-inline">175</span> miles. This is correct, but not very useful. We usually want the rate to reflect the number of miles in one hour. A rate that has a denominator of <span class="math-inline">1</span> unit is referred to as a **unit rate**.


<div class="definition-label">**Unit Rate**</div>


A **unit rate** is a rate with denominator of <span class="math-inline">1</span> unit.

Unit rates are very common in our lives. For example, when we say that we are driving at a speed of <span class="math-inline">68</span> miles per hour we mean that we travel <span class="math-inline">68</span> miles in <span class="math-inline">1</span> hour. We would write this rate as <span class="math-inline">68</span> miles/hour (read <span class="math-inline">68</span> miles per hour). The common abbreviation for this is <span class="math-inline">68</span> mph. Note that when no number is written before a unit, it is assumed to be <span class="math-inline">1.</span>

So <span class="math-inline">68</span> miles/hour really means <span class="math-inline">68 miles/1 hour.</span>

Two rates we often use when driving can be written in different forms, as shown:


Another example of unit rate that you may already know about is hourly pay rate. It is usually expressed as the amount of money earned for one hour of work. For example, if you are paid <span class="math-inline">$12.50</span> for each hour you work, you could write that your hourly (unit) pay rate is <span class="math-inline">$12.50/hour</span> (read <span class="math-inline">$12.50</span> per hour.)

To convert a rate to a unit rate, we divide the numerator by the denominator. This gives us a denominator of <span class="math-inline">1.</span>


<div class="example">
**Example**


Anita was paid <span class="math-inline">$384</span> last week for working <span class="math-inline">32 hours.</span> What is Anita’s hourly pay rate?


<div class="solution">
<span class="def-label">Solution</span>


 Start with a rate of dollars to hours. Then divide.
 <span class="math-inline">$384 last week for 32 hours</span>


 Write as a rate.
 <span class="math-inline"><sup>$384</sup>∕<sub>32 hours</sub></span>


 Divide the numerator by the denominator.
 <span class="math-inline"><sup>$12</sup>∕<sub>1 hour</sub></span>


 Rewrite as a rate.
 <span class="math-inline">$12/hour</span>


Anita’s hourly pay rate is <span class="math-inline">$12</span> per hour.

## Find Unit Price


Sometimes we buy common household items ‘in bulk’, where several items are packaged together and sold for one price. To compare the prices of different sized packages, we need to find the unit price. To find the unit price, divide the total price by the number of items. A **unit price** is a unit rate for one item.


<div class="definition-label">**Unit price**</div>


A **unit price** is a unit rate that gives the price of one item.


<div class="example">
**Example**


The grocery store charges <span class="math-inline">$3.99</span> for a case of <span class="math-inline">24</span> bottles of water. What is the unit price?


<div class="solution">
<span class="def-label">Solution</span>


What are we asked to find? We are asked to find the unit price, which is the price per bottle.


 Write as a rate.
 <span class="math-inline"><sup>$3.99</sup>∕<sub>24 bottles</sub></span>


 Divide to find the unit price.
 <span class="math-inline"><sup>$0.16625</sup>∕<sub>1 bottle</sub></span>


 Round the result to the nearest penny.
 <span class="math-inline"><sup>$0.17</sup>∕<sub>1 bottle</sub></span>


The unit price is approximately <span class="math-inline">$0.17</span> per bottle. Each bottle costs about <span class="math-inline">$0.17.</span>
