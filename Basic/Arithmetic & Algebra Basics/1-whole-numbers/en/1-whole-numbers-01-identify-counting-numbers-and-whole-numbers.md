## Identify Counting Numbers and Whole Numbers


Learning algebra is similar to learning a language. You start with a basic vocabulary and then add to it as you go along. You need to practice often until the vocabulary becomes easy to you. The more you use the vocabulary, the more familiar it becomes.

Algebra uses numbers and symbols to represent words and ideas. Let’s look at the numbers first. The most basic numbers used in algebra are those we use to count objects: <span class="math-inline">1,2,3,4,5,…</span> and so on. These are called the **counting numbers**. The notation “…” is called an ellipsis, which is another way to show “and so on”, or that the pattern continues endlessly. Counting numbers are also called natural numbers.


<div class="definition-label">**Counting Numbers**</div>


The counting numbers start with <span class="math-inline">1</span> and continue.


<div class="math-display">
1,2,3,4,5…
</div>


Counting numbers and whole numbers can be visualized on a **number line** as shown in .


*The numbers on the number line increase from left to right, and decrease from right to left.*

The point labeled <span class="math-inline">0</span> is called the **origin**. The points are equally spaced to the right of <span class="math-inline">0</span> and labeled with the counting numbers. When a number is paired with a point, it is called the **coordinate** of the point.

The discovery of the number zero was a big step in the history of mathematics. Including zero with the counting numbers gives a new set of numbers called the **whole numbers**.


<div class="definition-label">**Whole Numbers**</div>


The whole numbers are the counting numbers and zero.

## Identify the Place Value of a Digit


By looking at money and <span class="math-inline">base-10</span> blocks, we saw that each place in a number has a different value. A place value chart is a useful way to summarize this information. The place values are separated into groups of three, called periods. The **periods** are *ones, thousands, millions, billions, trillions*, and so on. In a written number, commas separate the periods.

Just as with the <span class="math-inline">base-10</span> blocks, where the value of the tens rod is ten times the value of the ones block and the value of the hundreds square is ten times the tens rod, the value of each place in the place-value chart is ten times the value of the place to the right of it.

- The digit <span class="math-inline">7</span> is in the ten thousands place. Its value is <span class="math-inline">70,000.</span>

- The digit <span class="math-inline">8</span> is in the thousands place. Its value is <span class="math-inline">8,000.</span>

- The digit <span class="math-inline">9</span> is in the tens place. Its value is <span class="math-inline">90.</span>

- The digit <span class="math-inline">4</span> is in the ones place. Its value is <span class="math-inline">4.</span>

## Use Place Value to Name Whole Numbers


When you write a check, you write out the number in words as well as in digits. To write a number in words, write the number in each period followed by the name of the period without the ‘s’ at the end. Start with the digit at the left, which has the largest place value. The commas separate the periods, so wherever there is a comma in the number, write a comma between the words. The ones period, which has the smallest place value, is not named.

So the number <span class="math-inline">37,519,248</span> is written thirty-seven million, five hundred nineteen thousand, two hundred forty-eight.

Notice that the word *and* is not used when naming a whole number.


<div class="definition-label">**Name a whole number in words.**</div>


- Starting at the digit on the left, name the number in each period, followed by the period name. Do not include the period name for the ones.

- Use commas in the number to separate the periods.

## Round Whole Numbers


In <span class="math-inline">2013,</span> the U.S. Census Bureau reported the population of the state of New York as <span class="math-inline">19,651,127</span> people. It might be enough to say that the population is approximately <span class="math-inline">20</span> million. The word *approximately* means that <span class="math-inline">20</span> million is not the exact population, but is close to the exact value.

The process of approximating a number is called **rounding**. Numbers are rounded to a specific place value depending on how much accuracy is needed. <span class="math-inline">20</span> million was achieved by rounding to the millions place. Had we rounded to the one hundred thousands place, we would have <span class="math-inline">19,700,000</span> as a result. Had we rounded to the ten thousands place, we would have <span class="math-inline">19,650,000</span> as a result, and so on. The place value to which we round to depends on how we need to use the number.

Using the number line can help you visualize and understand the rounding process. Look at the number line in . Suppose we want to round the number <span class="math-inline">76</span> to the nearest ten. Is <span class="math-inline">76</span> closer to <span class="math-inline">70</span> or <span class="math-inline">80</span> on the number line?


*We can see that <span class="math-inline">76</span> is closer to <span class="math-inline">80</span> than to <span class="math-inline">70.</span> So <span class="math-inline">76</span> rounded to the nearest ten is <span class="math-inline">80.</span>*

Now consider the number <span class="math-inline">72.</span> Find <span class="math-inline">72</span> in .


*We can see that <span class="math-inline">72</span> is closer to <span class="math-inline">70,</span> so <span class="math-inline">72</span> rounded to the nearest ten is <span class="math-inline">70.</span>*

How do we round <span class="math-inline">75</span> to the nearest ten. Find <span class="math-inline">75</span> in .


*The number <span class="math-inline">75</span> is exactly midway between <span class="math-inline">70</span> and <span class="math-inline">80.</span>*

So that everyone rounds the same way in cases like this, mathematicians have agreed to round to the higher number, <span class="math-inline">80.</span> So, <span class="math-inline">75</span> rounded to the nearest ten is <span class="math-inline">80.</span>

Now that we have looked at this process on the number line, we can introduce a more general procedure. To round a number to a specific place, look at the number to the right of that place. If the number is less than <span class="math-inline">5,</span> round down. If it is greater than or equal to <span class="math-inline">5,</span> round up.

So, for example, to round <span class="math-inline">76</span> to the nearest ten, we look at the digit in the ones place.

The digit in the ones place is a <span class="math-inline">6.</span> Because <span class="math-inline">6</span> is greater than or equal to <span class="math-inline">5,</span> we increase the digit in the tens place by one. So the <span class="math-inline">7</span> in the tens place becomes an <span class="math-inline">8.</span> Now, replace any digits to the right of the <span class="math-inline">8</span> with zeros. So, <span class="math-inline">76</span> rounds to <span class="math-inline">80.</span>

Let’s look again at **rounding** <span class="math-inline">72</span> to the nearest <span class="math-inline">10.</span> Again, we look to the ones place.

The digit in the ones place is <span class="math-inline">2.</span> Because <span class="math-inline">2</span> is less than <span class="math-inline">5,</span> we keep the digit in the tens place the same and replace the digits to the right of it with zero. So <span class="math-inline">72</span> rounded to the nearest ten is <span class="math-inline">70.</span>


<div class="definition-label">**Round a whole number to a specific place value.**</div>


- Locate the given place value. All digits to the left of that place value do not change unless the given place value is a 9, in which case it may. (See Step 3.)

- Underline the digit to the right of the given place value.

- Determine if this digit is greater than or equal to <span class="math-inline">5.</span>

  - Yes—add <span class="math-inline">1</span> to the digit in the given place value. If that digit is 9, replace it with 0 and add 1 to the digit immediately to its left. If that digit is also a 9, repeat.
  - No—do not change the digit in the given place value.

- Replace all digits to the right of the given place value with zeros.

  - Determine if this digit is greater than or equal to 5. If yes—add 1 to the digit in the given place value. If that digit is 9, replace it with 0 and add 1 to the digit immediately to its left. If that digit is also a 9, repeat. If no—do not change the digit in the given place value.
  - Replace all digits to the right of the given place value with zeros.
